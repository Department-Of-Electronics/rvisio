# SoC documentation

The datasheet (user manual) is not stored here – the simulator generates it from the current SoC configuration:
**System on chip (SoC) → "📄 Datasheet"**. It opens a page with an overview and block diagram, the memory
map, the processor and caches, the interrupt system and, for every peripheral, a register table, bits,
timings and a C example (names as in `soc.h` from "⬇ VS Code project"). This way the student gets the datasheet
of their own board. At the top of the page is "🖨 Save as PDF" (print → "Save as PDF").
